# FM / AM RX 説明書

FM / AM RX は、ひとつの周波数を選んで、その電波を音声にして聞くための App です。FM 放送(ワイド FM)、特定小電力トランシーバーや業務無線などの狭帯域 FM(NFM)、AM の 3 つの方式に対応しています。
画面には、受信している帯域全体のスペクトラムとウォーターフォール、聞いているチャネルだけを拡大したスペクトラムとウォーターフォール、信号の強さと音声の状態が表示されます。

画面のタッチ、ソフトキー、数値入力などのすべての App に共通する操作は、[共通の操作](README.md)を見てください。

## できること

- 70 MHz から 6 GHz までの周波数を 1 つ選び、FM(ワイド / ナロー)または AM で復調して、PC のスピーカーから聞く
- スケルチ(信号が弱いときに音を消す機能)のしきい値を決める
- 受信帯域全体(1.92 MHz 幅)と、聞いているチャネルの周辺(240 kHz 幅)を、スペクトラムとウォーターフォールで同時に見る
- 信号の強さと音声の大きさをメーターで見る
- 音声だけを消す(`MUTE`)

## 用意するもの

| 機材 | 内容 |
|---|---|
| アンテナ | 聞きたい周波数帯に合ったもの。`RX PORT` で選んだ端子につなぎます |
| スピーカー | PC 内蔵のスピーカー、またはイヤホン。音量は OS の設定で調整します |

方式と周波数のおおよその目安は次のとおりです。

| 方式 | 主な用途 | チャネル幅 |
|---|---|---|
| `WFM` | FM 放送(日本では 76〜95 MHz) | 200 kHz |
| `NFM` | 特定小電力トランシーバー(422 MHz 帯)、業務無線、アマチュア無線の FM など | 12.5 kHz |
| `AM` | 航空無線(118〜136 MHz)など AM の通信 | 10 kHz |

> 注意: 自分あての通信でない無線の内容を、他人に漏らしたり、自分や他人のために利用したりすることは、電波法(第 59 条)で禁じられています。受信した内容の扱いに注意してください。

## 起動と終了

1. メニューで、必要なら `GAIN` と `RX PORT` を合わせます。
2. App の一覧で `FM / AM RX` をタップします。
3. 受信が始まると、ステータスバーの帯が `STREAMING`(緑)になり、この App の画面が開きます。
4. 起動したら、まず `RX FREQ` の表示を確かめ、聞きたい周波数と違うときは合わせ直してください。

終わるときは `BACK` を押します。受信が止まり、メニューに戻ります。

画面は上から、受信帯域全体の表示、チャネルの表示、復調パネルの 3 つに分かれています。

### 受信帯域全体の表示(上段)

B210 が受信している 1.92 MHz 幅の全体です。上がスペクトラム、下がウォーターフォール(時間の経過につれて上から下へ流れる、信号の強さの色の帯)です。

| 表示 | 意味 |
|---|---|
| `CENTER` | 受信機の中心周波数(局部発振器の周波数)。聞いている周波数ではありません。ここはタップしても変えられません。周波数は `RX FREQ` で選びます |
| `SPAN` | 表示している周波数の幅(1.920 MHz) |
| `RBW` | 周波数の分解能(1 本の線が表す幅) |
| `REF / DIV` | 縦軸のいちばん上の値と、1 目盛の dB。タップすると基準の値を入力できます(下の「表示範囲を変える」を参照) |
| `PEAK` / `PEAK OFFSET` | 表示の中でいちばん強い信号の強さと、その位置(中心からの差) |
| `NOISE FLOOR` | 雑音の大きさのおおよその値 |
| `AVG` / `FPS` | 表示の平均回数と、1 秒あたりの更新回数 |
| `DISC` | 受信データに切れ目ができたときに赤く光ります |
| 琥珀色の縦線 `RX` | いま聞いているチャネルの位置 |
| 緑の線 / 暗い黄色の線 | いまのスペクトラム / それまでの最大値 |
| ウォーターフォール右上の `7 s` など | ウォーターフォール全体で何秒分を表示しているか |

聞いているチャネルは、わざと中心からずらしてあります(初期値は中心より 250 kHz 上)。受信機の仕組みで、中心には信号がなくても小さな線(DC スパイク)が出るため、聞くチャネルがそれに重ならないようにしています。このずれは `LO OFS` で変えられます。

### チャネルの表示(中段)

`CHANNEL IQ  demod.channel  240 kHz` と書いてある段です。聞いているチャネルを中心にした 240 kHz 幅を、フィルタを通したあとの状態で表示します。
表示欄の意味は上段と同じです。こちらの `CENTER` は聞いている周波数(`RX FREQ` と同じ値)です。

フィルタの外側は大きく下がって表示されるので、チャネルに入っている信号だけが山になって見えます。山の幅が、選んだ方式のチャネル幅のおおよその目安です。

### 復調パネル(下段)

| 表示 | 意味 |
|---|---|
| `CARRIER`(緑)/ `SQUELCHED`(灰) | 信号の強さがスケルチのしきい値以上なら `CARRIER` で、音が出ます。しきい値より弱いと `SQUELCHED` で、音は消えます |
| `RX FREQ` | 聞いている周波数。タップすると周波数を入力できます(ソフトキーの `RX FREQ` と同じ) |
| `MODE` | 復調の方式(`WFM` / `NFM` / `AM`) |
| `CH BW` | 方式に応じたチャネル幅 |
| `LO / OFFSET` | 受信機の中心周波数と、聞いているチャネルのずれ |
| `AUDIO` | 音声の状態。`ON` は再生中、`MUTE` は消音中、`ERROR`(赤)は音声を出せない状態です。`ERROR` のときは、パネルの下に赤字で理由が出ます |
| `UNDER/OVER` | 音声の途切れ(`UNDER`)と、あふれ(`OVER`)の回数。0 以外は琥珀色になります |
| `LATENCY` | 受信してから音が出るまでの遅れ |
| `DROPS` | 復調に使う受信データを取りこぼした回数。0 なら緑、1 以上は赤です |
| `CHANNEL POWER (dBFS)` | チャネルの信号の強さ(−100〜0 dBFS)。琥珀色の縦の印がスケルチのしきい値です。緑の棒がこの印を越えると音が出ます |
| `AUDIO (dBFS)` | 出ている音声の大きさ(−60〜0 dBFS)。スケルチが閉じている間は振れません |

信号の強さの値(dBFS)は、`GAIN` の設定によって変わります。同じ電波でも、利得を上げると大きく表示されます。

## 操作

### ソフトキー

| キー | 動作 |
|---|---|
| `RX FREQ` | 聞く周波数を入力します(70 MHz〜6 GHz)。入力画面の題は `CENTER FREQUENCY` ですが、入れる値は聞く周波数です。受信機の中心は、`LO OFS` の分だけ自動でずらして合わせます |
| `MODE WFM` / `MODE NFM` / `MODE AM` | 押すたびに方式が `NFM` → `WFM` → `AM` → `NFM` の順に変わります。キーには、いまの方式が表示されます |
| `SQUELCH` | スケルチのしきい値を dBFS で入力します(−150〜0 dBFS)。初期値は −70 dBFS です |
| `LO OFS` | 受信機の中心と聞くチャネルのずれを入力します(−900〜+900 kHz)。聞いている周波数は変わらず、受信機の中心のほうが動きます |
| `MUTE` | 押すたびに、受信音声の消音とその解除が切り替わります。消音中はキーが反転します。操作の音は消えません |
| `BACK` | App を止めてメニューに戻ります |

この App には `DIAG` キーがありません。診断画面を見るときは、`BACK` でメニューに戻り、一覧の `DIAGNOSTICS` から開いてください。

### 画面のタップ

| 場所 | 動作 |
|---|---|
| 復調パネルの `RX FREQ` | ソフトキーの `RX FREQ` と同じです |
| 上段の `REF / DIV` | 上段の表示範囲の基準(いちばん上の値)を入力します |
| 中段の `REF / DIV` | 中段の表示範囲の基準を入力します |

右下に `≡` の印がある欄はタップできます。

### 表示範囲を変える

`REF / DIV` をタップすると `REFERENCE LEVEL (TOP OF SCALE)` の入力が開きます(−150〜+20 dBFS)。入力した値が縦軸のいちばん上になり、そこから 90 dB 下までを表示します(1 目盛 9 dB)。
はじめて使うときは、表示範囲が自動で 1 回だけ合わせられます。そのあとは、入力した値が使われ続けます。

### 音量

この App には音量のキーがありません。音量は OS の設定で調整します。

## 使いかたの例

### FM 放送を聞く

1. FM 放送用のアンテナ(または長めのワイヤー)をつなぎ、メニューから `FM / AM RX` を始めます。
2. `MODE` を押して `MODE WFM` にします。
3. `RX FREQ` を押し、`8` `0` `.` `0` `MHz` のように放送局の周波数を入力します。
4. `CARRIER` が緑になり、音が出ます。出ないときは `SQUELCH` を下げるか、`GAIN` を見直します。

### 特定小電力トランシーバーを聞く

1. 400 MHz 帯のアンテナをつなぎ、`FM / AM RX` を始めます。
2. `MODE NFM` になっていることを確かめます(初期値は `NFM` です)。
3. `RX FREQ` で聞きたいチャネルの周波数(例: 422.2 MHz なら `4` `2` `2` `.` `2` `MHz`)を入力します。
4. 送信がない間に `CHANNEL POWER` の緑の棒の位置を見て、それより少し上(5〜10 dB 程度)に `SQUELCH` を合わせます。送信が始まったときだけ `CARRIER` になり、音が出ます。

### スケルチを合わせる

- 雑音がずっと聞こえる: しきい値が雑音より下にあります。`SQUELCH` で値を上げます。
- 信号が来ているのに音が出ない、または途切れる: しきい値が高すぎます。`SQUELCH` で値を下げます。
- スケルチを使わずに常に音を出したいときは、`SQUELCH` に −150 を入力します。

### チャネルの近くに邪魔な線があるとき

上段のスペクトラムで、琥珀色の `RX` の線のすぐ近くに強い線(受信機の中心の線や、ほかの不要な信号)があるときは、`LO OFS` で別の値(例: `-` を付けて −250 kHz)を入れると、聞く周波数はそのままで、受信機の中心が反対側に移ります。

## 保存される設定

次の設定は自動で保存され、次に App を始めたときに元に戻ります。

| 設定 | 内容 |
|---|---|
| `MODE` | 復調の方式 |
| `LO OFS` | 受信機の中心と聞くチャネルのずれ |
| `SQUELCH` | スケルチのしきい値 |
| `MUTE` | 消音のオン / オフ |
| 表示範囲 | 上段と中段それぞれの `REF / DIV` と平均回数 |

周波数はこの App では保存しません。メニューの `LAST CENTER`(最後に使った受信機の中心周波数)をもとに始まるので、起動したら `RX FREQ` を確かめてください。
利得と受信端子はメニューの設定で、[共通の操作](README.md)のとおり保存されます。

## 出力されるファイル

この App は録音のファイルを作りません。
信号がスケルチを越えたときと下回ったとき(`carrier detected` / `carrier lost`)は出来事として記録され、診断画面の `EVENT LOG` と `~/spear/logs/` のログに残ります。

## 困ったとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 音が出ない(`SQUELCHED` のまま) | 信号がスケルチのしきい値より弱い | `CHANNEL POWER` の棒と琥珀色の印を見比べ、`SQUELCH` を下げます。アンテナ、`RX PORT`、`GAIN` も確かめます |
| 音が出ない(`CARRIER` なのに無音) | 消音中、または OS の音量が 0 | `AUDIO` が `MUTE` なら `MUTE` を押して解除します。OS の音量を確かめます |
| `AUDIO` が赤の `ERROR` になる | 音声の出力先を開けない | パネル下の赤字の理由を見ます。ほかのプログラムが音声装置を使っていないか、OS の音声設定を確かめ、App を始め直します |
| 雑音ばかり聞こえる | スケルチのしきい値が低い、または周波数・方式が違う | `SQUELCH` を上げます。`RX FREQ` と `MODE` を確かめます |
| 声がひずむ、割れる | 方式が合っていない、または信号が強すぎる | `MODE` を確かめます(放送は `WFM`、無線機は `NFM`)。強い局の近くでは `GAIN` を下げます |
| 声が小さい、こもる | 狭帯域の通信を `WFM` で聞いている | `MODE NFM` にします |
| 音がときどき途切れる、`UNDER/OVER` が増える | PC の処理が追いつかない | ほかの重いプログラムを止め、AC 電源につなぎます |
| `DROPS` が赤になる | 受信データの取りこぼし | 上と同じです。続くときは診断画面で `STREAM BUS` と `EVENT LOG` を確かめます |
| 聞きたい周波数に合わせたのに、上段の中心に信号がない | 中心は受信機の中心で、聞くチャネルは `LO OFS` の分ずれている | 正常です。琥珀色の `RX` の線の位置が聞いているチャネルです |
| 起動したら周波数が前回と違う | 周波数はこの App では保存していない | `RX FREQ` で合わせ直します |
| 周波数を入力すると赤い帯が出て受け付けない | 範囲外(70 MHz〜6 GHz) | 範囲内の値を入れ直します |

## 制限事項

- 一度に聞けるのは 1 チャネルだけです。
- 選べる方式は `WFM`、`NFM`、`AM` の 3 つです。SSB や CW、デジタル方式の復調はできません。チャネル幅は方式ごとに決まっていて、変えられません。
- `WFM` はモノラルです。ステレオや RDS には対応していません。
- `AM` には自動で音量をそろえる機能(AGC)がありません。信号の強さによって音の大きさが変わります。
- 音量の調整は OS 側で行います。この App に音量のキーはありません。
- 受信機の中心と聞くチャネルのずれ(`LO OFS`)は、受信帯域の中に収まる範囲に自動で制限されます。とくに `WFM` では、入力した値より小さくなることがあります。大きなずれのまま方式を変えるとチャネルの端が帯域からはみ出すことがあるので、ふだんは初期値(+250 kHz)のまま使ってください。
- スペクトラム上をタップして周波数を選ぶことはできません。周波数は `RX FREQ` で入力します。
- 受信した音声を録音する機能はありません。電波そのものを残したいときは IQ RECORDER を使ってください。

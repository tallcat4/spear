# SPECTRUM 説明書

SPECTRUM は、受信した電波をスペクトラム(周波数ごとの強さのグラフ)とウォーターフォール(その時間変化を色で表した図)で表示する App です。
周波数を自由に変えて、どこにどんな電波が出ているかを探したり、アンテナや受信の設定がうまくいっているかを確かめたりするのに使います。
音声の復調や録音はしません。聞くときは FM / AM RX、録音するときは IQ RECORDER を使ってください。

![SPECTRUM](../gui/spectrum_b210.png)

## できること

- 70 MHz から 6 GHz までの好きな周波数を中心に、サンプルレートと同じ幅(0.2〜10 MHz)の範囲を一度に見る
- いちばん強い信号の強さと位置、ノイズの床(雑音の高さ)を数値で読む
- 最大値の保持(`HOLD`)で、短い間だけ出る電波の跡を残す
- 平均化(`AVG`)で、表示のちらつきを抑える
- 表示の上端(基準レベル)を数値で決める

## 用意するもの

- B210 と、見たい周波数帯に合ったアンテナ。アンテナはメニューの `RX PORT` で選んだ受信端子につなぎます。
- 機材の全体は [共通の操作](README.md) の「用意するもの」を見てください。

## 起動と終了

1. メニューの一覧で `SPECTRUM` をタップします。
2. 受信が始まると、スペクトラムとウォーターフォールが動き出します。
3. 終わるときは右下の `BACK` を押します。受信を止めてメニューに戻ります。

周波数とサンプルレートは、前回 SPECTRUM・IQ RECORDER・FM / AM RX などで最後に使っていた値から始まります(メニューの `LAST CENTER` / `LAST RATE`)。
利得(`GAIN`)と受信端子(`RX PORT`)はメニューで決めます。App を使っている間は変えられないので、変えるときは一度 `BACK` でメニューに戻ってください。

## 画面の見かた

画面は上から、読み出し行、スペクトラム、ウォーターフォールの 3 段です。上のステータスバーと下のソフトキーについては [共通の操作](README.md) を見てください。

### 読み出し行

| 表示 | 意味 |
|---|---|
| `CENTER` | 中心の受信周波数。枠で囲まれていて、タップすると周波数の数値入力が開きます |
| `SPAN` | 画面の左端から右端までの周波数の幅。サンプルレートと同じ値です |
| `RBW` | 周波数の分解能。どれだけ近い 2 つの信号を見分けられるかの目安です(`SPAN` の 1/1024) |
| `REF / DIV` | 表示の上端のレベル(dBFS)と、横線 1 目盛りあたりの dB。枠で囲まれていて、タップすると基準レベルの数値入力が開きます |
| `PEAK` | いま画面の中でいちばん強い点のレベル(緑の数字) |
| `PEAK OFFSET` | そのいちばん強い点が、中心から何 kHz / MHz ずれているか。`+` は中心より高い側、`-` は低い側です |
| `NOISE FLOOR` | 雑音の高さの目安(画面全体の中央の値) |
| `AVG` | 平均化の回数。枠で囲まれていて、タップするとソフトキーの `AVG` と同じように切り替わります |
| `FPS` | 1 秒あたりの画面の更新回数 |
| `DISC` | ふだんは暗い文字です。受信データに切れ目ができたときに赤く点きます |

レベルの単位 dBFS は、B210 が扱える最大の強さを 0 とした値です。数字が 0 に近いほど強く、ふつうはマイナスの値になります。
アンテナに届いた電力(dBm)ではないので、ほかの受信機の値とはそのまま比べられません。利得(`GAIN`)を上げれば同じ電波でも大きな値になります。

### スペクトラム

- 横軸は周波数です。真ん中の目盛りが中心周波数(絶対値)で、そのほかの目盛りは中心からのずれ(`+` / `-`)です。
- 縦軸はレベル(dBFS)です。縦横とも 10 目盛りで、真ん中の線は少し明るく描いてあります。
- 明るい緑の線が、いまの受信のようすです。
- 暗い琥珀色の線は最大値の保持(`HOLD`)です。これまでに出たいちばん高いレベルを残します。

### ウォーターフォール

- スペクトラムの時間変化を色で表します。いちばん上が最新で、時間がたつと下へ流れていきます。
- 左上の `0 s` が現在、右上の秒数が画面の下端までの時間です。
- 色は、弱いほうから黒 → 紺 → 青 → 水色 → 緑 → 黄 → 白の順です。白は表示の上端に届いている(それ以上の強さは区別できない)ことを示します。
- 色の範囲は、スペクトラムと同じ表示範囲(`REF / DIV`)に合わせてあります。
- 中央の縦線が中心周波数です。

## 操作

### ソフトキー

| キー | 動作 |
|---|---|
| `FREQ` | 中心周波数の数値入力を開きます。入力できるのは 70 MHz〜6 GHz です。確定するとすぐにその周波数に変わります |
| `-1 MHz` | 中心周波数を 1 MHz 下げます |
| `+1 MHz` | 中心周波数を 1 MHz 上げます |
| `RATE` | サンプルレートの数値入力を開きます。入力できるのは 200 ksps〜10 Msps です。確定すると App をいったん止めて、新しいレートで始め直します(少しの間、表示が止まります) |
| `REF LVL` | 基準レベル(表示の上端)の数値入力を開きます。入力できるのは -150〜+20 dBFS です。表示範囲は、入れた値から 90 dB 下までになります(1 目盛り 9 dB) |
| `AVG` | 平均化の回数を 1 → 2 → 4 → 8 → 16 → 1 … の順に切り替えます。キーにいまの回数が出ます(例: `AVG 4`)。大きくすると表示は落ち着きますが、変化への反応が遅くなります |
| `HOLD` | 最大値の保持の入/切です。白く反転しているときが入です。押すたびに、それまでに残った最大値は消えます |
| `BACK` | 受信を止めてメニューに戻ります |

数値の入れかた(数字を打ってから単位のキーで確定する、など)は [共通の操作](README.md) の「数値の入力」を見てください。
読み出し行の `CENTER` をタップしても `FREQ` と同じ入力が、`REF / DIV` をタップしても `REF LVL` と同じ入力が開きます。

### 表示範囲について

- 基準レベルを一度も決めていないときは、受信を始めた直後に、雑音の高さに合わせて表示範囲を自動で決めます。自動で決めるのはその 1 回だけで、あとは変わりません。
- `REF LVL` で決めた値は覚えておき、次からはその範囲で表示します。

## 使いかたの例

### 知っている周波数の電波を探す

1. `FREQ` を押し、見たい周波数を入れます(例: `4` `3` `3` `MHz`)。
2. 電波が出ると、スペクトラムに山が立ち、ウォーターフォールに線が出ます。
3. `PEAK OFFSET` を見ると、その山が中心からどれだけずれているかが分かります。たとえば中心 422.000 MHz で `+200.0 kHz` なら、電波は 422.200 MHz です。

### 広い範囲をざっと調べる

1. `RATE` を大きめ(例: 8 Msps)にすると、一度に見える幅が広がります。
2. `-1 MHz` / `+1 MHz` で少しずつ動かすか、`FREQ` で飛びます。
3. 間欠的にしか出ない電波は `HOLD` を入にしておくと、出た跡が琥珀色の線で残ります。探す場所を変えたら `HOLD` を 2 回押すと、跡を消して入に戻せます。

### 弱い信号を見やすくする

1. `AVG` を 8 や 16 にすると、雑音のちらつきが減って弱い山が見えやすくなります。
2. 山が画面の下のほうに埋もれているときは、`REF LVL` で上端を下げます(例: `NOISE FLOOR` より 60 dB くらい上)。
3. それでも弱いときは、`BACK` でメニューに戻って `GAIN` を上げてから始め直します。

### 信号が強すぎるとき

ウォーターフォールが真っ白になる、スペクトラムの山が上端に張りつく、`PEAK` が 0 dBFS に近い、といったときは、まず `REF LVL` で上端を上げて確かめます。
`PEAK` が 0 dBFS 近くまで来ているなら入力が大きすぎます。メニューで `GAIN` を下げてください。

## 保存される設定

次の設定は自動で保存され、次に SPECTRUM を開いたとき(S.P.E.A.R. を起動し直したときも)に元に戻ります。

| 設定 | 内容 |
|---|---|
| 基準レベル(`REF LVL`) | 表示範囲。一度も決めていなければ、毎回自動で決めます |
| 平均化(`AVG`) | 平均化の回数。初めは 4 です |
| 中心周波数・サンプルレート | 最後に使った値から始まります(これは SPECTRUM だけでなく、ほかの App と共通です) |

`HOLD` の入/切は保存されません。開くたびに入から始まります。

## 困ったとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 何も表示されない、動かない | B210 の準備ができていない、または切れている | ステータスバーの装置の状態を見ます。メニューの `DIAGNOSTICS` で詳しく確かめます([共通の操作](README.md)) |
| 雑音だけで電波が見えない | 周波数が違う、アンテナが合っていない、つないだ端子と `RX PORT` が違う | 周波数を確かめます。アンテナを `RX PORT` で選んだ端子につないでいるか確かめます。利得を上げます |
| 表示が画面の上か下に張りついている | 表示範囲が信号に合っていない | `REF LVL` で上端を合わせ直します |
| 画面全体が白っぽい、山が平らに切れている | 入力が強すぎる | メニューで `GAIN` を下げます |
| `DISC` がときどき赤く点く | PC の処理が追いつかず、受信データが途切れた | サンプルレートを下げる、ほかの重いプログラムを止める、AC 電源につなぐ |
| `RATE` を変えたら表示がしばらく止まった | レートを変えるときは App を始め直すため | そのまま待てば再開します |
| `FREQ` で値を確定できない | 範囲外(70 MHz〜6 GHz)の値 | 赤い帯の理由を見て、入れ直します |
| 診断画面を開くキーがない | SPECTRUM のソフトキーには `DIAG` がありません | `BACK` でメニューに戻り、一覧の `DIAGNOSTICS` から開きます |

## 制限事項

- 受信専用です。表示するだけで、復調・録音はしません。
- 見える幅はサンプルレートで決まり、最大 10 MHz です。それより広い範囲を一度に掃引する機能はありません。
- 周波数の刻みは、ソフトキーでは 1 MHz だけです。細かく合わせるときは `FREQ` で数値を入れます。
- レベルは dBFS(受信機の最大値に対する相対値)で、アンテナ端の電力ではありません。利得によって値が変わります。
- 利得と受信端子は、App を使っている間は変えられません。メニューで決めてから App を始めます。
- マーカーや、画面のタッチで拡大・移動する機能はありません。

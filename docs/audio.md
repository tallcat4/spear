# 音声の大きさと音量

## 方針
- 音量の持ち主は OS(PipeWire の既定の出力)の 1 か所だけ。`AudioSink` と App は音量を持たない。
- どの App の声も、AudioSink に渡す前に同じ大きさにそろえる(`dsp::Leveler`)。OS の音量を最大にすれば声も最大近くで鳴る。
- 起動音・操作音(`UiAudio`)にはレベル合わせを掛けない。

## レベル合わせ(`dsp/leveler.hpp`)
2026-11-03 の測定(声のある所の rms / 最大、dBFS): 起動音 約 −3 / −3、JR TRAIN −25 / −1〜−4、STD-T98 −30〜−34 / −17。
声が起動音より 20〜30 dB 小さく、OS の音量を最大にしても声だけが小さかった。

| 段 | 内容 |
|---|---|
| AGC | 10 ms ごとの rms がゲート(−50 dBFS)より上の所だけ平均電力を追い(時定数 1.5 s。話し始めと 2 s 以上の無音のあとは累積平均で速く)、目標(既定 −18 dBFS)にする利得を求める。利得は −12〜+24 dB、50 ms でなめらかに。無音・ゲートより下の雑音では利得を変えない |
| リミッタ | 先読み 3 ms(= 群遅延)で、出力を −1 dBFS に抑える。戻りは 80 ms |

- 掛ける所: JR TRAIN(合成音声)、STD-T98(ミックス後)、SLPR(ミックス後)、FM/AM(スケルチ後)。AudioSink に渡す直前だけ。
  保存(WAV)・Stream Bus の観測点・メーターの値には掛けない。
- 設定(site.conf、全 App 共通): `audio_level_dbfs=-18`(目標。−40〜−6 に制限)、`audio_level_dbfs=off` で掛けない。
- 録音した音声に通した結果(2026-11-03): JR TRAIN D4 V1(2026-10-22、ENH / JRV)−18.8 / −19.2 dBFS・最大 −1.0、
  STD-T98 の 2.6 s の抜粋 −21〜−24 dBFS(短いので出だしの大きな音節の影響が残る)。
- テスト: `tests/test_leveler.cpp`(大小の入力が同じ大きさになる、上限、無音で利得が動かない、群遅延)。
